# Recovery guides

Each guide is one Markdown file in this folder. It shows up on /recovery-guides/ by itself.
Only use the clinic's own documents. Don't write medical content that the clinic didn't give us.

1. Copy `TEMPLATE.md` to a new file named for the web address, like `acl-repair.md`
   (the page will be /recovery-guides/acl-repair/).
2. Change `published: false` to `published: true`.
3. Fill in the top section and paste the clinic's text below the `---` line.
   Use `## ` for section headings, like "Weeks 0 to 2".
